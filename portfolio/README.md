# RodnyPHP Portfolio - Complete Deployment Package

## Quick Start for InfinityFree

### Files included:
- index.php (Homepage)
- calculator.php (Calculator tool)
- admin/index.php (Admin panel)
- admin/banner-api.php (Banner API)
- api/analytics.php (Analytics API)
- api/status.php (Status check)
- assets/css/style.css (Styles)
- assets/js/app.js (JavaScript)
- storage/ (Data storage folder)

### Upload Instructions:

1. Extract this ZIP file
2. Upload the contents to your InfinityFree `htdocs/` folder
3. Delete any old `index.html` file
4. Set folder permissions to 755:
   - admin/
   - api/
   - storage/
5. Test: https://your-domain.free.nf/

### Test URLs:
- Homepage: https://your-domain.free.nf/
- Calculator: https://your-domain.free.nf/calculator.php
- Admin: https://your-domain.free.nf/admin/
- Status: https://your-domain.free.nf/api/status.php
