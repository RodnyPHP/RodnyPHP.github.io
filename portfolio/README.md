# Static GitHub Pages portfolio

This directory contains the GitHub Pages-compatible version of the portfolio. Open [`index.html`](./index.html) or visit `/portfolio/` after GitHub Pages publishes it.

GitHub Pages serves static HTML, CSS, and JavaScript only. The original PHP files remain as a server-side reference but are not executed here. The admin demo stores edits in `localStorage` in the current browser; it is not authentication and must not be used for private data.
